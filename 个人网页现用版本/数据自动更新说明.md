# 内蒙古经济数据自动更新系统 — 说明文档

## 一、系统概述

`backend/auto_update.py` 是一个全自动数据采集脚本，定期从内蒙古自治区官方网站抓取最新经济数据，更新 `内蒙古经济数据总表.csv` 并重新导入数据库。

**已安装 Windows 定时任务**：每年 **2月1日** 和 **4月15日** 上午 9:00 自动执行。

---

## 二、数据来源网站

### 数据源 1：内蒙古统计局 — 年度统计公报
- **网址**：https://tj.nmg.gov.cn/tjyw/tjgb/
- **发布时间**：每年 **3-4月** 发布上一年度公报
- **内容**：最权威的年度全面经济数据，涵盖 GDP、人口、财政、进出口、居民收入消费、物价指数、工业产量、新能源装机等
- **爬取方式**：自动查找最新"国民经济和社会发展统计公报"链接，正则提取正文数据 + 解析附表

### 数据源 2：内蒙古统计局 — 经济运行数据发布
- **网址**：https://tj.nmg.gov.cn/tjdt/fbyjd_11654/
- **发布时间**：每年 **1月下旬** 发布上一年度经济快报
- **内容**：GDP初步数据、三产结构、工业产品产量、消费、投资、居民收入等（比统计公报早2-3个月发布，但数据范围更少）
- **爬取方式**：自动查找"20XX年全区经济..."标题链接，复用统计公报解析器

### 数据源 3：内蒙古自治区财政厅 — 预算收支
- **网址**：https://czt.nmg.gov.cn/zwgk/zfxxgk/fdzdgknr/czsj/
- **发布时间**：每年 **1月中旬** 发布上一年度1-12月财政收支
- **内容**：一般公共预算收入/支出、税收收入、非税收入
- **爬取方式**：自动查找"XXXX年1-12月全区一般公共预算"链接，正则提取文本数据

## 五、覆盖率统计

| 分类 | 可自动更新 | 不可自动更新 | 占比 |
|------|-----------|-------------|------|
| 总计（257项） | **46** | **211** | 17.9% |
| 核心宏观指标 | 几乎全覆盖 | — | — |
| 分行业/分地区明细 | 极少 | 大部分 | — |

> **说明**：虽然只覆盖 18% 的指标数量，但覆盖了几乎所有前端可视化中的**核心宏观经济指标**（GDP、人口、财政收支总额、居民收入消费、CPI/PPI、进出口总额、风电光伏装机、煤炭产量等）。分行业/分城市的明细数据主要来自国家统计局年鉴和非公开的专项数据源，需要人工维护。

## 六、使用方式

```bash
# 手动试运行（不写入文件，只看能提取什么数据）
python backend/auto_update.py --dry-run

# 手动运行（实际更新 CSV + 重新导入数据库）
python backend/auto_update.py

# 安装 Windows 定时任务
python backend/auto_update.py --install

# 卸载定时任务
python backend/auto_update.py --uninstall
```

## 七、系统时间线

| 时间 | 事件 | 自动操作 |
|------|------|----------|
| 每年 1月下旬 | 统计局发布"全区经济运行"快报 + 财政厅发布年度财政收支 | — |
| **每年 2月1日 9:00** | 定时任务第1次触发 | 抓取经济运行快报 + 财政数据，获得 GDP、收入、CPI 等初步数据 |
| 每年 3-4月 | 统计局发布上一年度统计公报（最全面） | — |
| **每年 4月15日 9:00** | 定时任务第2次触发 | 抓取统计公报，获得完整数据（公报数据更权威，覆盖更多指标）|

> 如果电脑在触发时间关机，Windows Task Scheduler 会在下次开机时自动补跑（`StartWhenAvailable=true`）。
